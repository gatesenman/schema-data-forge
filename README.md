# Schema Data Forge

Desktop editor that generates JSON/XML sample data from JSON Schema and XML Schema using AI, with mandatory schema validation.

## Overview
Schema Data Forge is a desktop tool for generating realistic sample data from schemas, powered by AI, with strict schema validation.

## Features
- JSON Schema → sample data
- XML Schema → sample data
- AI-assisted generation
- Mandatory schema validation
- Desktop application

- Python
